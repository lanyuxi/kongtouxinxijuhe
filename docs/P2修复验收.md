# P2 修复验收记录

已完成原审查第 8、9 条的本地实现：页面信息层次，以及收藏、进度、返回、反馈和失败恢复的功能闭环。修改仍在当前项目目录，未提交、推送或部署。

## 页面使用变化

- 保留蓝紫色风格。首页先显示搜索、状态、新手筛选和重置，再显示项目入口；高级条件、来源检查、统计和安全说明可展开查看。来源异常数量仍在折叠标题中显示，不隐藏抓取失败。
- 手机主导航五个入口同时可见，不需要横向滑动。默认 390×844 首屏实测能显示搜索及第一张项目卡片；卡片底部约为 843 像素，无横向溢出。
- 详情保留一个主要操作：“查看参与教程”或“查看研究清单”。先展示核心结论、风险依据和成本，再进入教程；评分、相对分位、证据和项目背景放在后面的折叠区。移除重复的资料和结论面板。
- 手机提供教程、成本、证据、注意事项四个快捷入口。跳转会展开对应证据面板，并让标题避开固定导航；320 像素实测教程顶部约 237 像素，导航底部 222 像素。
- 浅色正文加深；键盘焦点显示蓝色实线。首访引导约束 Tab/Shift+Tab 焦点、支持 Esc 和焦点恢复，并允许内容在小屏内滚动。

## 功能使用变化

- 未收藏时步骤控件禁用，就地说明“先收藏后可记录步骤”。收藏后可记录研究清单；第三方未经核验的教程仍保持原有禁用规则。
- 详情返回原列表视图，保留搜索、公链等筛选、高级条件、来源和总览展开状态、滚动位置。详情历史记录各自保存来源，连续浏览多个列表再后退不会串到其他列表。
- **备份入口在“我的关注”**：导出 JSON；换浏览器后导入。导入先校验整份文件，再合并收藏；同一项目已有记录优先。不会上传文件，不需要账号。当前资料库未收录的收藏仍保留。
- 步骤身份由内容生成，教程带版本。步骤重排沿用可识别的勾选；步骤变更或旧记录只有序号时需要复核，不把旧序号套到新动作。普通勾选和进度操作不会消除提醒，须明确点击“确认已复核当前教程”；未复核时不能标记完成。
- 网络失败、404、资料损坏分别说明，列表和详情均可重试。详情、初始列表、重新加载入口采用一致的渲染字段校验；坏资料不会直接进入页面。导入读取期间新增的收藏也保留，存储写入失败不会报告导入成功。
- 热门页没有合格项目时说明“尚无达到热门精选标准的项目”，不提示降低筛选或降低证据标准。可领取页也区分没有核验活动与普通筛选空结果。
- 反馈链接预填项目名称、详情和公开资料来源，说明需要 GitHub 登录；只提供入口，没有代用户创建 Issue。
