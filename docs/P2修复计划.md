# P2 实施与验收计划

依据：已批准的审查报告第 8、9 条。保留现有蓝紫主题及 P0/P1 的可信性约束，在当前目录修改；不推送、不发布、不新增服务端。

1. 首页与导航：用途说明、搜索、新手入口、简短检查状态、卡片前移；高级筛选和统计/来源信息折叠，始终可重置。手机 390×844 默认页面能看到搜索及至少一个项目入口；全部主导航无需横滑。验证：SSR 顺序与折叠状态、桌面/手机截图、键盘焦点。
2. 详情层次：核心结论、资格/期限/成本/风险与最近核验前置，教程随后，评分与来源细节后置并折叠。删除重复结论和资料区，保留单一主操作和移动教程索引。验证：中文状态、来源护栏、可见顺序、未收藏禁用及就地原因。
3. 返回上下文：记录每个列表视图的筛选、总览、展开状态及滚动位置；详情返回原视图，直接访问详情默认返回最新页。验证：关注/热门来源、筛选与滚动恢复、浏览器后退。
4. 本地记录：导出 JSON；导入先完整校验再合并，不覆盖现有项目记录；旧步骤序号不得套到新教程。生成稳定步骤 ID 与教程版本，重排保留可识别的步骤，修改或旧记录提示复核；不删除收藏。验证：备份往返、非法/超大文件、合并不丢数据、重排/内容变化/遗留记录。
5. 加载与空态：网络失败、404 和数据损坏分开，失败可以重试；初始列表失败也可重试。热门/可领取页区分没有合格项目与筛选无结果，不降低证据标准。反馈入口预填项目与链接，说明 GitHub 登录，不代替用户提交。验证：失败分类、重试、空状态与反馈链接。
6. 可访问性与收尾：首访弹窗约束焦点、Esc 关闭与焦点恢复；统一清晰焦点环、正文对比度及减少动画偏好。验证：键盘及放大/窄屏阅读、完整测试/类型/构建/数据校验，独立只读代码复核。

技术选择：沿用 hash 路由与原生 details；备份只在浏览器内读写。列表也保留短的教程版本/步骤 ID，避免用户必须打开详情才能发现教程已变。版本由实质步骤内容计算，采集时间变化不触发复核。重复且无法区分的步骤在版本改变时保守要求重新核对。

边界：导入采用合并且已有记录优先；仅暂停受影响的步骤，不把完成研究等同奖励资格。不会顺手更改活动事实、评分标准或资金操作规则。无完整辅助技术审计，不宣称符合全部可访问性标准。

进度：六项实施与本地验收已完成；独立复核发现的缺陷已修补并复验。详细证据见 P2修复验收.md；尚未提交、推送或部署。
