# 访客独立 X 配置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每位访客可以通过中文设置页面保存并真实检测 X 凭据，独立抓取和查看项目方最新动态。

**Architecture:** 公共静态数据与个人 X 数据分开，个人接口由同源 Node 后台提供。浏览器通过 HttpOnly 会话 Cookie 识别访客，后台加密保存凭据、维护任务并原子发布个人结果；个人请求不启动共用数据流水线。

**Tech Stack:** 现有 React、TypeScript、Vite、Vitest、Playwright；Node 内置 HTTP、crypto、fs，以及现有 tsx。不新增数据库、登录系统或翻译服务。

**Spec:** `docs/superpowers/specs/2026-10-01-访客独立X配置-design.md`（用户已通过）

## Global Constraints

- 会话有效期为 30 天；访问设置或个人抓取接口时续期。
- 个人抓取最多 40 个账号，每账号最多 10 条近期推文，按账号去重。
- 账号查询与推文读取均成功才能通过检测；不得用 oEmbed 替代推文检测。
- 已保存密钥不回显、不进入浏览器持久化、日志、Git 或公开文件。
- 删除、替换配置或会话过期后，旧任务不能写回；失败不覆盖最后成功数据。
- 个人抓取不修改公共 `data/`、领取状态、评分和教程；分别展示公共及个人检查时间。
- 中文界面；英文内容仅作为明确标记的推文原文展示。
- 本机先实现验证；无有效 Token 时真实 X 接入未验收，无线上后台时线上接入未验收。

## Review Focus

- 浏览器收到静态站点的 HTML 而不是 API JSON：应识别后台不可用，不能误报配置成功。（任务 5）
- 删除或更换密钥时旧请求还未结束：旧请求不得恢复配置或结果。（任务 3、4）
- Cookie 伪造、重复、过期或请求携带其他访客 ID：不得访问别人的配置和数据。（任务 1、3）
- X 返回 HTTP 200 但结构损坏，或错误正文包含输入密钥：不能判为成功或泄漏正文。（任务 2）
- 原有列表加载失败或窄屏导航空间不足：仍能进入并使用设置。（任务 5、7）

## 文件边界与接口约定

新增 `src/lib/x-api-types.ts` 定义浏览器与后台共享的纯类型：

- `XFailure`: `{ code: 'invalid_input' | 'invalid_token' | 'forbidden' | 'credits' | 'rate_limit' | 'not_found' | 'timeout' | 'network' | 'upstream' | 'invalid_response' | 'not_configured' | 'busy' | 'interrupted'; message: string }`。
- `XPost`: `{ id: string; text: string; url: string; publishedAt: string | null; airdropSignal: boolean }`。
- `XTarget`: `{ handle: string; slugs: string[] }`。
- `XAccountResult`: `{ handle: string; slugs: string[]; checkedAt: string; posts: XPost[]; stale: boolean }`。
- `XTask`: `{ id: string; state: 'running' | 'success' | 'partial' | 'failed'; checked: number; total: number; startedAt: string; finishedAt: string | null; failures: { handle: string; error: XFailure }[] }`。
- `XSettings`: `{ configured: boolean; testedAt: string | null; testError: XFailure | null; task: XTask | null }`。
- `XResult`: `{ task: XTask | null; lastSuccessAt: string | null; accounts: XAccountResult[] }`。
- `XReply<T>`: `{ ok: true; data: T } | { ok: false; error: XFailure }`。

API 不接收会话 ID、文件路径、上游 URL 或访问别人结果的参数。所有响应 `Cache-Control: no-store`；状态响应无密钥。设置页面收到 404、HTML 或无效结构时，独立显示“当前部署未接入配置后台”，不影响公共数据浏览。
