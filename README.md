# DropLens · 空投雷达与决策助手

> **看清每一个空投，而不是盲目参与。**

DropLens 是一个面向空投新手的**轻量情报与决策工具**：聚合空投线索 → 交叉验证来源 → 计算真实性置信度 / 风险 / 参与价值 → 生成新手可执行教程。

它不是「自动撸空投」工具，只回答 4 个问题：

1. 最近有什么新的空投机会？
2. 这个项目是真的假的、可信度怎么样？
3. 值不值得我投入时间、Gas 和资金？
4. 如果值得做，我下一步具体怎么操作？

---

## 核心特性

- **零服务器、零数据库**：纯静态站点，数据以 JSON 随仓库发布
- **三套独立评分**：真实性置信度 / 风险等级 / 参与价值，**不合成总分**
- **每个评分可解释**：每项评分都附带得分理由与证据链接
- **证据交叉验证**：第三方链接不会自动被视为官方链接
- **一票否决机制**：索取私钥 / 助记词等行为直接判为极高风险，且永不推荐参与
- **数据源故障隔离**：单个来源抓取失败不会清空已有数据，保留 Last Known Good
- **本地收藏与进度**：仅使用浏览器 LocalStorage，不上传任何用户数据
- **全站简体中文 + 浅色主题**：无深色背景，无成片英文 UI

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite |
| 样式 | Tailwind CSS（浅色主题） |
| 数据 | 静态 JSON |
| 数据处理 | Node.js + tsx（纯函数引擎） |
| 自动化 | CNB 流水线（crontab 每 3 小时） |
| 用户状态 | LocalStorage |
| 测试 | Vitest |

> 相对原方案（GitHub Pages + Actions）改为 **CNB 流水线 + JSON 制品**，
> 架构约束完全一致：不要数据库、不要后台、不要常驻服务。

## 快速开始

```bash
npm install

# 1) 生成数据（抓取 → 归一 → 合并 → 验证 → 评分 → 教程 → 校验）
npm run pipeline

# 2) 本地开发
npm run dev

# 3) 构建静态站点

# 4) 测试与校验

```

## 数据流水线

```text
数据源适配器（独立运行 + 故障隔离）
   ↓
Normalize        结构归一
   ↓
Merge            按 slug 去重；保留上一版数据（Last Known Good）
   ↓
Verify           证据收集；第三方链接需交叉验证才可信
   ↓
Enrich           用人工核实的官方档案补全官方链接
   ↓
Score            真实性置信度 / 风险 / 参与价值
   ↓
Guide            分步骤教程 + FAQ（模板化，来源可追溯）
   ↓
Validate         不通过则拒绝写入，避免污染线上数据
   ↓
Write JSON       airdrops.json + details/*.json + source-health.json
```

### 评分模型

**真实性置信度（满分 100）**

| 证据项 | 分值 |
|---|---:|
| 官方网站可验证 | 15 |
| 官方公告明确提到活动 | 20 |
| 官网 ↔ X ↔ Docs 链接可互相印证 | 15 |
| 至少两个独立第三方来源 | 15 |
| Galxe / Layer3 等官方 Space 可确认 | 10 |
| 官方 GitHub / Docs 有持续活动 | 10 |
| 团队 / 投资信息可核实 | 10 |
| 合约地址在区块浏览器可验证 | 5 |

**风险等级**：`low / medium / high / critical`。
命中一票否决规则（索取助记词、私钥、Keystore、要求向个人地址转账等）直接判为 `critical`。

**参与价值（满分 100）**：项目基本面 20 + 融资 15 + 活跃度 15 + 信号强度 20 + 投入产出比 15 + 时机 10 + 稀释风险 5。
等级：`85+ S / 70+ A / 55+ B / 40+ C / 其余 D`。

> **风险为 critical 时，无论价值多少，一律显示「不建议参与」。**

## 核心不变量

实现与校验均围绕以下不变量，任何改动不得违反：

1. 没有证据的项目不能显示为「已验证」
2. 任何评分必须能解释「为什么得到这个分数」
3. 一个数据源抓取失败，不能导致整个空投库被清空
4. 第三方页面提供的链接，不能自动被认为是官方链接
5. 浏览器端永远不能出现 API Secret
6. 任何页面不得要求用户输入助记词 / 私钥
7. 系统只能表达证据置信度 / 风险评估 / 参与价值，不得承诺收益或安全性

这些不变量由 `npm test`（21 个单测）与 `npm run validate` 共同保障。

## 自动化（CNB 流水线）

| 触发 | 行为 |
|---|---|
| `crontab: 17 */3 * * *` | 每 3 小时抓取数据 → 测试 → 校验 → 数据有变化则提交回仓库 |
| `push` (main) | 安装 → 生成数据 → 测试 → 校验 → 构建 → 发布 Release |
| `pull_request` | 安装 → 生成数据 → 测试 → 校验 → 构建 |

定时任务避开整点（每 3 小时的 `:17`），减少任务集中。

